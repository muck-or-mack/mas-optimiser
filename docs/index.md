# mas-optimiser

An LLM agent run on the EnterpriseOps-Gym benchmark, measured properly, with
every failure explained down to the database cell and the turn that set it;
on top of that, a ladder of harnesses and an optimiser that improves the
best of them by editing its planning layer. The README covers installation
and use; this documentation holds how the code works, the methods behind
the measurements and decisions, the data model of each domain and the API.
